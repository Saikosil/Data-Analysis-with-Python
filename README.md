# Data-Analysis-with-Python

This repository contains a comprehensive data analysis project that walks through the essential stages of working with real-world data,
from raw data collection to building and refining machine learning regression models.
It includes two parallel projects focused on price prediction in different domains:
- Used Car Pricing
- Laptop Pricing
Each project follows the same structured approach to data preparation, modeling, and evaluation, providing a hands-on comparison of how machine learning techniques can be applied across different datasets and use cases.

# Topics Covered
- Collecting and importing data
- Cleaning, preparing, and formatting data
- DataFrame manipulation using Pandas
- Summarizing data with statistics and visualizations
- Building machine learning regression models
- Refining and evaluating models
- Creating automated data pipelines
